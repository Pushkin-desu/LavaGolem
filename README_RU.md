# LavaGolem

Плагин для Paper (Minecraft 1.21), добавляющий автоматических Медных Големов, которые собирают лаву из котлов и складывают её в сундуки.

[English README](README.md)

## Требования

Paper **1.21.9 или новее** (требуется сущность Медного Голема).

## Возможности

- Создай Лавового Голема, кликнув правой кнопкой по блоку с предметом **Сердце голема**
- Голем самостоятельно берёт пустые вёдра из отмеченного сундука, набирает лаву из котлов и складывает вёдра с лавой в сундук-приёмник
- Зажми Shift и кликни правой кнопкой по голему **пустой рукой**, чтобы разобрать его и получить сердце обратно
- Кликни правой кнопкой по голему для просмотра его статистики
- Големы сохраняются после перезапуска сервера

## Рецепт

Крафт по форме: 4 медных слитка по углам, 4 красных камня крестом, 1 ведро с лавой в центре.

```
М К М
К Л К
М К М
```

*(М = Медный слиток, К = Красный камень, Л = Ведро с лавой)*

## Настройка

1. Поставь **сундук с вёдрами** поблизости и прикрепи к любой из его сторон табличку с текстом `[Buckets]` на первой строке
2. Поставь рядом **котёл с лавой**
3. Поставь **сундук-приёмник** поблизости и прикрепи табличку с текстом `[Lava]` на первой строке
4. Возьми Сердце голема и кликни правой кнопкой по земле — голем появится

## Команды

| Команда | Привилегия | Описание |
|---------|-----------|----------|
| `/removegolems` | `lavagolem.admin` | Удалить всех лавовых големов |
| `/golemstats`   | `lavagolem.admin` | Показать общую статистику |

## Конфигурация

Редактируй `plugins/LavaGolem/config.yml`:

```yaml
search-radius: 8          # Радиус поиска сундуков/котлов (в блоках)
reach-distance: 2.2       # Расстояние, с которого голем считает цель достигнутой
search-cooldown-ticks: 40 # Задержка перед повторным поиском при неудаче (тики)
tick-period: 10           # Как часто выполняется логика голема (тики)
bucket-sign-text: "[Buckets]"
lava-sign-text: "[Lava]"
locale: ru                # en или ru
bstats: true              # Анонимная статистика использования
```

## Сборка

Требуется Java 21 и Maven 3.x.

```bash
mvn clean package
```

Готовый jar будет в `target/lavagolem-1.0.0.jar`.
