# LavaGolem

Плагин для Paper (Minecraft 1.21), добавляющий пятерых автоматических Медных Големов: один носит лаву из котлов, второй следит за печами, третий варит зелья, четвёртый ловит рыбу, пятый развозит предметы между складами.

[English README](README.md) · [Полное руководство и решение проблем](GUIDE_RU.md)

## Требования

Paper **1.21.9 или новее** (требуется сущность Медного Голема).

## Големы

### 🪣 Лавовый голем
Берёт пустое ведро из контейнера `[Buckets]`, набирает лаву из полного котла и складывает ведро с лавой в контейнер `[Lava]`. Бесконечно.

### 🔥 Голем-печник
Загружает печи и выносит готовое — без воронок и рельсов.

- Берёт самое многочисленное сырьё из `[Smelt]`, подбирает топливо из `[Fuel]` так, чтобы ничего не сгорело впустую, и относит результат в `[Output]`.
- Раскидывает большую партию поровну по всем свободным печам, а не сваливает всё в одну.
- Достаёт пустое ведро после того, как ведро лавы прогорело, — печь не забивается.
- Работает с **обычными печами, плавильными печами и коптильнями**, раскладывая автоматически: руда → плавильня, еда → коптильня, остальное → обычная печь.
- ПКМ по нему — меню с режимами работы: **Баланс**, **Только грузить**, **Только забирать**.

### ⚗️ Голем-алхимик
Ведёт твои варочные стойки — без раздатчиков и воронок.

- **Один сундук на всё** — кидай стеклянные бутылки, незеровый нарост, огненный порошок (или стержни) и ингредиенты в единственный `[Brew]`; голем сам разберётся, что для чего.
- **Сам ходит за водой** — набирает бутылки из источника или котла с водой (который наполняет дождь/капельница).
- **Варит по ступеням** — вода → нарост → мутное → ингредиент эффекта → один модификатор, потом уносит зелья в `[Output]`. Варит, пока ингредиенты есть в сундуке.
- **Выбор, что варить** — в меню список всех зелий настоящими зельями; клик включает/выключает каждое (и модификаторы тоже). По умолчанию всё включено; если подходящих ингредиентов несколько, берётся самый многочисленный.
- **Держит в топливе только одну щепотку порошка** (это уже 20 варок), остальной остаётся на зелья силы.
- **Мелет огненные стержни** в порошок на верстаке по настоящему ванильному рецепту.

### 🎣 Голем-рыбак
Ловит рыбу в твоём пруду по ванильным весам рыбалки.

- **Расходует твои удочки** — берёт удочку из `[Rods]`, ловит, пока не сломается, берёт следующую. Удочка *и есть* плата за работу: ~64 поклёвки примерно по 18 минут.
- **Важны зачарования твоей удочки** — Удача рыбака улучшает улов, Приманка сокращает ожидание, Прочность продлевает жизнь удочке. **Починка не делает ничего**: голем не получает опыт, так что удочки правда кончаются.
- **Сокровищам нужна открытая вода**, ровно как в ваниле — 5×5 воды с воздухом сверху. В ямке 1×1 будет вечно рыба и хлам и ни одного сокровища.
- **Раскладывает улов** — добавь необязательный контейнер `[Treasure]`, и сокровища поедут туда, а рыба и хлам в `[Output]`.

### 📦 Голем-курьер
Носит предметы между помеченными контейнерами по маршрутам, которые ты задаёшь в GUI.

- **Маршруты** — сколько угодно, каждый переносит предметы из одного тега в другой. ЛКМ по слоту — листать теги поблизости, ПКМ — ввести любой свой тег в чат.
- **Фильтр предметов** — шифт-клик по предмету в своём инвентаре добавляет его в фильтр; для каждого маршрута фильтр работает как **чёрный список** (по умолчанию) или **белый**.
- **Статус** — меню прямо говорит, почему маршрут не идёт (нет источника, приёмник полон, фильтр ничего не пропускает, оба конца — один и тот же сундук).
- **Сам находит дорогу** — прокладывает каждый маршрут собственным поиском пути (в отдельном потоке) по закэшированной карте проходимой земли, а короткие участки между поворотами — лестницы, двери, углы — доверяет ванильной навигации. Таблички `[Waypoint]` теперь не обязательны: клетки рядом с ними дешевле для поиска, поэтому голем предпочитает дорогу, которую ты построил, а если поиск вообще ничего не находит — вейпоинты остаются запасным вариантом. Если до цели правда не дойти, голем честно об этом скажет, а не схитрит: вернёт груз в исходный контейнер, допишет к имени `(stuck)`, покажет причину в статусе маршрута — и будет пробовать снова с растущей паузой между попытками (`courier-teleport`, по умолчанию выключен, возвращает старое поведение с телепортом).

## Рецепты

У всех пятерых одна форма — меняется только центр:

```
М К М        М = Медный слиток
К X К        К = Красный камень
М К М
```

| Голем | Центр `X` |
|---|---|
| Лавовый голем | Ведро с лавой |
| Голем-печник | Печь |
| Голем-алхимик | Варочная стойка |
| Голем-рыбак | Удочка |
| Голем-курьер | Воронка |

Получается **Сердце голема**. Кликни им правой кнопкой по земле — голем появится.

## Пометка контейнеров

Хранилищем может быть **сундук, сундук-ловушка, бочка или шалкер**. Пометить можно двумя способами:
- повесить **табличку** с нужным текстом на любую из 6 сторон, **или**
- **переименовать сам контейнер** в наковальне в этот текст (без таблички — чище смотрится).

| Тег | Кто использует |
|---|---|
| `[Buckets]` | Лавовый — пустые вёдра |
| `[Lava]` | Лавовый — вёдра с лавой |
| `[Smelt]` | Печник — сырьё на переплавку |
| `[Fuel]` | Печник — любое ванильное топливо |
| `[Output]` | Печник — готовое (вёдра возвращаются сюда же); Алхимик — зелья; Рыбак — улов |
| `[Brew]` | Алхимик — бутылки, топливо и ингредиенты, всё вместе |
| `[Rods]` | Рыбак — удочки на расход |
| `[Treasure]` | Рыбак — необязательный; сокровища падают сюда вместо `[Output]` |
| *любой* | Курьер — маршруты используют любые теги, какие введёшь |

Это только **значения по умолчанию**. В меню любого голема ПКМ по слоту контейнера задаёт тег **конкретно этому голему** (ЛКМ — сброс), так что две однотипные станции спокойно стоят рядом и не делят один `[Output]`.

## Повседневное использование

- **Как различать** — лавовый голем горит (только визуально, урона не получает), алхимик окружён магическими частицами, рыбак держит удочку. Без ресурспака.
- **Статистика / настройки** — ПКМ по голему пустой рукой открывает его меню.
- **Как выключить** — в меню любого голема есть кнопка питания; голем встаёт на месте, пока не включишь обратно.
- **Разобрать** — Shift + ПКМ пустой рукой; Сердце вернётся вместе со всем, что голем нёс.
- Големы, их текущая работа, режим и маршруты переживают перезапуск сервера.

## Владение и защита

- **Кто поставил — тот и хозяин.** Само Сердце никак не помечается (его можно свободно продавать/дарить) — владельцем становится тот, кто **поставил** голема. Голем, поставленный до 1.1.0, хозяина не имеет и по-прежнему работает для всех, как и раньше.
- **Чужим големом не воспользоваться** — меню, теги, маршруты, разборка — доступны только хозяину, если у игрока нет `lavagolem.use.others`.
- **Переносишь старую станцию?** `/lavagolem claim` забирает ближайшего голема без хозяина (в радиусе 12 блоков) *на месте*, сохраняя его статистику, теги и режим. Разобрать и поставить заново — это новый голем с обнулённой статистикой; почти всегда нужен именно `claim`.
- **Лимит, если он нужен.** `max-golems-per-player` (по умолчанию `0` — без ограничений) ограничивает число одновременно поставленных големов у игрока; `lavagolem.limit.bypass` снимает лимит. Отказ в установке не тратит Сердце.

| Право | По умолчанию | Что даёт |
|---|---|---|
| `lavagolem.craft` | true | Крафтить Сердце голема |
| `lavagolem.place` | true | Поставить Сердце и создать голема |
| `lavagolem.use` | true | Пользоваться своими големами — меню, теги, маршруты, разборка |
| `lavagolem.use.others` | op | Пользоваться чужим големом |
| `lavagolem.limit.bypass` | op | Игнорировать `max-golems-per-player` |
| `lavagolem.admin` | op | Все подкоманды `/lavagolem` |

**Защита контейнеров.** Если установлен GriefPrevention или WorldGuard, доступ *владельческого* голема к контейнерам проверяется по нему (для GriefPrevention — клеймы и доверие к контейнерам, для WorldGuard — флаг `CHEST_ACCESS`); безхозный голем по-прежнему не проверяется вообще, как и раньше. Для остальных плагинов защиты есть общий запасной механизм, но он срабатывает только пока хозяин голема онлайн. `protection-mode` определяет, что делать, когда хозяина не достать напрямую: `cached` (по умолчанию) доверяет последнему записанному вердикту, `strict` отказывает во всём непроверенном, `off` полностью выключает проверки.

Адаптеры GriefPrevention и WorldGuard **пока не проверялись на живом сервере** с этими плагинами — считай их экспериментальными, не проверенными на практике. Ни один хук не получает слепого доверия: если он ведёт себя не так, его просто игнорируют, а не позволяют заклинить голема, и после повторных сбоев он сам отключается.

## Команды

Всё живёт под `/lavagolem` (кратко `/lg`), и на всё нужна привилегия `lavagolem.admin`.

| Команда | Описание |
|---------|----------|
| `/lavagolem reload` | Перечитать `config.yml` без перезапуска сервера |
| `/lavagolem stats` | Показать общую статистику |
| `/lavagolem debug [all\|<роль>]` | Трассировка решений: без аргумента — ближайший голем в радиусе 12 блоков, `all` — все, либо название роли (`courier`, `smelter`, …). Пишет, почему голем не работает, в чат или в файл |
| `/lavagolem claim` | Стать владельцем ближайшего голема без хозяина в радиусе 12 блоков |
| `/lavagolem remove <all\|ник>` | Удалить всех големов или только големов одного игрока |

`/lavagolem remove` намеренно не работает без аргумента: она удаляет чужих големов вместе со своими,
а такое лучше не запускать по мышечной памяти.

Старые имена — `/removegolems`, `/golemstats`, `/golemdebug`, `/golemclaim` — по-прежнему работают и
требуют ту же привилегию, но объявлены устаревшими и подскажут, чем их заменить.

## Конфигурация

Редактируй `plugins/LavaGolem/config.yml`:

```yaml
search-radius: 8          # Радиус поиска сундуков/котлов/печей (в блоках)
reach-distance: 2.2       # Расстояние, с которого голем считает цель достигнутой
search-cooldown-ticks: 40 # Задержка перед повторным поиском при неудаче (тики)
tick-period: 10           # Как часто выполняется логика голема (тики)
bucket-sign-text: "[Buckets]"
lava-sign-text: "[Lava]"
smelt-sign-text: "[Smelt]"
fuel-sign-text: "[Fuel]"
output-sign-text: "[Output]"
brew-sign-text: "[Brew]"  # Алхимик: бутылки + топливо + ингредиенты в одном контейнере
rods-sign-text: "[Rods]"  # Рыбак: удочки на расход
treasure-sign-text: "[Treasure]" # Рыбак: необязательный, сокровища едут сюда вместо [Output]

fisher-min-wait-ticks: 100 # Только рыбак: ванильное окно 100-600 тиков; Приманка снимает 100 за уровень
fisher-max-wait-ticks: 600
fisher-treasure: true     # false = только рыба и хлам
fisher-custom-catches: [] # свои предметы в улове — см. ниже

# Включение/выключение големов (по умолчанию все включены). Выключенного нельзя скрафтить/поставить.
enable-lava-golem: true
enable-smelter-golem: true
enable-courier-golem: true
enable-alchemist-golem: true
enable-fisher-golem: true

courier-search-radius: 24 # Только курьер: одинаков во все стороны, должен покрывать оба конца маршрута (макс. 32)
courier-carry-limit: 16   # Сколько предметов курьер несёт за рейс
waypoint-sign-text: "[Waypoint]" # Необязательно: клетки рядом с меткой дешевле для поиска, плюс это запасной вариант, если поиск не сработал
courier-teleport: false   # Пережиток на случай геометрии, которую правда не обойти ногами; выключен, чтобы застрявший голем пробовал снова, а не читерил мимо сломанной инфраструктуры

# --- Навигация ---
# Каждый голем прокладывает путь собственным поиском (в отдельном потоке) по закэшированной карте
# проходимой земли; ваниль отвечает только за короткие отрезки (лестницы, двери, узкие проходы).
# Големы ходят только по загруженным чанкам, в пределах nav-search-margin от цели — это не для
# доставки грузов через незагруженную местность. Есть ещё много ключей nav-* — см. полное руководство.
nav-max-distance: 256     # Как далеко (в блоках) может уйти один поиск маршрута, прежде чем сдаться
nav-search-margin: 32     # Насколько маршрут может отклоняться от прямой к цели (в блоках)
nav-chunk-cache-seconds: 600 # Сколько секунд карта проходимости чанка считается свежей до пересборки

# --- Владение и лимит големов ---
max-golems-per-player: 0  # Максимум големов у одного игрока одновременно (0 = без ограничений)

# --- Защита контейнеров ---
protection-mode: cached       # cached | strict | off — что делать, если хозяина голема не достать напрямую
protection-cache-seconds: 300 # Сколько секунд доверять последнему вердикту как запасному варианту офлайн

golemdebug-output: chat   # chat | file | both — куда идёт трассировка /lavagolem debug
locale: ru                # en или ru
bstats: true              # Анонимная статистика использования
```

Курьер сканирует куб, поэтому стоимость растёт как радиус³ — держи `courier-search-radius` ровно таким, какой нужен твоим маршрутам.

**Свой лут.** Добавь в улов рыбака любой предмет через `fisher-custom-catches`. Каждая запись идёт в один пул и конкурирует там с ванильными предметами по весу:

```yaml
fisher-custom-catches:
  - { material: DIAMOND, weight: 2, amount: 1, pool: treasure }
  - { material: EMERALD, weight: 5, amount: 1, pool: junk }
```

`pool` — `fish`, `junk` или `treasure`; запись в `treasure` выпадает лишь на ~5% забросов, что дают сокровище, и едет по правилам `[Treasure]`. Примерные суммы весов пулов: рыба ~100, хлам ~100, сокровища ~6. Предметы из конфига выдаются как есть (без ванильного износа и зачаров).

## Сборка

Требуется Java 21 и Maven 3.x.

```bash
mvn clean package
```

Готовый jar будет в `target/lavagolem-1.1.0.jar`.
